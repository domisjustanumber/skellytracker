# Running Demos

The package installs the console script `skellytracker`. With `uv`, run it as `uv run skellytracker`.

## Run a pipeline on a camera

The option `--pipeline` runs a pipeline on a live camera, in the running mode `live`. Its value is a
key of the pipeline catalog or the path of a pipeline file. The demo opens an OpenCV window with the
outputs on the frame. Press `q` or `Esc` to stop.

```bash
uv run skellytracker --pipeline mediapipe-holistic-tasks@skellytracker
uv run skellytracker --pipeline yolox-rtmw-wholebody@skellytracker --ep cpu
```

| Option | Meaning |
|---|---|
| `--camera N` | The camera index. Default: 0. |
| `--rotate D` | Turn each frame clockwise by `D` degrees before tracking: 0, 90, 180 or 270. Default: 0. |
| `--ep KEY` | A key of the EP catalog, for example `cpu`. |
| `--ep-option NAME=VALUE` | One EP option. You can give it more than one time. |
| `--device KEY` | One GPU key. You can give it more than one time. |
| `--cpu-threads N` | The threads of each session on the CPU EP. |
| `--preprocess MODE` | The place of the preprocess: `auto`, `cpu` or `gpu`. Default: `auto`. |

The options `--ep`, `--ep-option`, `--device`, `--cpu-threads` and `--preprocess` need `--pipeline`.

With no `--ep`, the demo uses the recommended EP and prints it. It does this only when the pipeline
needs an EP. The pipeline `mediapipe-holistic-tasks` needs no EP.
[Execution Providers](../core-concepts/execution-providers) explains the EP keys.

## Check a pipeline file

```bash
# Run the load checks of a pipeline file or a pipeline key, and print the warnings
uv run skellytracker validate my.pipeline.yaml

# List the node types, with their ports and params
uv run skellytracker nodes
uv run skellytracker nodes --json
```

`validate` prints `<pipeline_id>@<source.name>: valid` for a good file.
[Pipeline Overview](../core-concepts/pipeline-overview) explains the pipeline file.

## List the detectors

```bash
uv run skellytracker detectors
```

[Detectors](../core-concepts/detectors) explains the detector catalog.
