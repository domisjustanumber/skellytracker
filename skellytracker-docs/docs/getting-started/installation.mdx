# Installation

## Requirements

- Python 3.13.18.
- Windows on x86_64, Linux on x86_64 or macOS on Apple Silicon (arm64).

macOS on Intel (x86_64) is not supported.

## Install the package

```bash
pip install skellytracker

# Or with uv
uv add skellytracker
```

The base package includes ONNX Runtime 1.30. ONNX Runtime gives these execution providers (EPs):

- the CPU EP, on each platform;
- the CoreML EP, on macOS;
- the DirectML EP, on Windows. It is in a field test and needs an opt-in.

## Add MediaPipe

The pipeline `mediapipe-holistic-tasks@skellytracker` needs the extra `mediapipe`:

```bash
pip install "skellytracker[mediapipe]"
uv add "skellytracker[mediapipe]"
```

At the first run, MediaPipe downloads its model file to `~/.freemocap/skellytracker-models`.
This step needs network access.

## ONNX model files

The package holds no ONNX model file. The pipeline `yolox-rtmw-wholebody@skellytracker` needs the
ONNX files of its two models. When a file is missing, the pipeline catalog shows the pipeline as not
available, with the reason:

```python
from skellytracker.core.pipelines import list_pipelines

for entry in list_pipelines():
    print(entry.key, entry.version, entry.available, entry.needs_execution_provider)
    if not entry.available:
        print("  ", entry.unavailable_reason)
```

## GPU execution providers

A GPU EP for an NVIDIA GPU is a plugin EP pack. The command `skellytracker-eps install` puts the pack
in the EP store of the user. Before you install, look at the EP state of your system:

```bash
uv run skellytracker-eps status       # the EP state of this host; no network
uv run skellytracker-eps recommend    # the recommended EP of this host
```

[GPU Setup](../guides/gpu-setup) gives the install procedure.
[Execution Providers](../core-concepts/execution-providers) explains the EP keys and the EP store.

## Install from source

```bash
git clone https://github.com/freemocap/skellytracker.git
cd skellytracker
uv sync --all-extras
```

[Development](../development) gives the test and contribution steps.
