# Decision log of `{{MODULE}}/`

This log records the decisions that apply only to `{{MODULE}}/`. The Rules of the root log apply to
this log: `../{{ROOT}}decisions/README.md#rules`. To write an entry, use the root template
`../{{ROOT}}decisions/template.md`. Read this file and [open-work.md](open-work.md) before you change
a file in this module. Also read the root index and the root open work. Read an entry of
[historical.md](historical.md) only to find the reason for a decision.
